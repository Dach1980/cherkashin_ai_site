## Tech stack

- Plain HTML, CSS, and JavaScript; no build step or package installation.
- Responsive layout for desktop, tablet, and mobile.
- RU/EN language switcher.
- Reduced-motion accessibility support.
- External links open in a new tab with safe rel attributes.

## Run locally

Open `index.html` in a browser. For a local server, run from this directory:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the default branch and the `/(root)` folder, then save.
4. Wait for GitHub Pages to publish the site; the public URL will be shown in the Pages settings.
