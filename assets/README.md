# Brand assets

- `logo-dch-ai.svg` — scalable neon D + CH + AI logo concept, for site branding and larger displays.
- `favicon.svg` — simplified square icon for browser tabs and bookmarks.

The SVG files are editable vector approximations of the approved visual direction. Raster exports (PNG 32×32, 180×180 and 512×512) can be generated from these assets when needed.
